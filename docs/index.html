MCP.everything

One object covering every part of the Model Context Protocol, spec revision 2026-07-28. Where the spec allows a fixed set of values, you get a dropdown with every option. Fixed values are written as they are. Values you supply yourself are shown as a type.

New to MCP? Start with Learn MCP, a step-by-step path built from the questions I asked while learning it.

Dropdown values were taken from the type definitions in the official Python SDK (mcp 2.3.0) and checked against the 2026-07-28 specification. Copy JSON uses whatever you currently have selected, and writes your-own values as placeholders such as "<string>".

  
Fields in tasks follow the Tasks extension docs. The SDK still carries older 2025-11-25 task types with different names, so check the ext-tasks repository before implementing them.
